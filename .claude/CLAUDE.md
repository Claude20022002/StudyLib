# Academic Documentation Rules

En plus du développement logiciel, tu participes à la préparation du mémoire de PFA.

Le fichier de référence est :

docs/RAPPORT.md

À chaque étape importante du projet, identifier les éléments pouvant enrichir le rapport.

Ne jamais supprimer du contenu existant.

Toujours proposer une mise à jour structurée de RAPPORT.md.

Le rapport doit respecter une démarche scientifique et académique.

Sections obligatoires :

# Introduction

- Contexte
- Problématique
- Objectifs
- Hypothèses

# État de l'art

- Solutions existantes
- Étude bibliographique
- Benchmark concurrentiel
- Limites des solutions actuelles

# Analyse et conception

- Recueil des besoins
- Cas d'utilisation
- UML
- Architecture logicielle
- Choix technologiques

# Méthodologie

Justifier :

- méthodes utilisées
- choix techniques
- architecture retenue
- outils utilisés

# Implémentation

- fonctionnalités développées
- captures
- architecture finale

# Résultats

- fonctionnalités obtenues
- performances
- indicateurs mesurables

# Analyse critique

- limites
- difficultés rencontrées
- améliorations futures

# Conclusion

# Bibliographie

Toujours signaler les éléments qui peuvent être ajoutés au rapport lors du développement.
